Como configurar um domínio customizado

  1. Me diga qual domínio você quer usar (ex: meusite.com). Posso criar um arquivo CNAME automaticamente com esse domínio.
  2. No provedor onde o domínio está registrado, aponte os registros DNS conforme as instruções do GitHub Pages: geralmente registros A para os IPs do GitHub ou um registro CNAME para username.github.io.
  3. No GitHub, vá em Settings → Pages e verifique se o domínio customizado aparece corretamente e se o HTTPS está habilitado.
